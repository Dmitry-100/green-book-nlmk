# Принятые риски

Реестр осознанно принятых рисков безопасности. Каждая запись должна иметь
владельца, обоснование и условие пересмотра.

## AR-1: Открытая саморегистрация с автоодобрением

**Дата:** 2026-06-10
**Владелец:** Дмитрий Сотников
**Серьёзность (если бы не принимался):** High

**Что:** `POST /api/auth/register` создаёт учётную запись сразу со статусом
`approved`/`is_active=true`; `login()` дополнительно авто-апрувит pending-аккаунты
(`backend/app/routers/auth.py`).

**Почему принято:** пилотная фаза — тестировщики должны входить без ручного
одобрения администратором. Портал доступен только из корпоративного периметра.

**Компенсирующие меры:**
- жёсткий rate-limit на `login`/`register` (`AUTH_RATE_LIMIT_PER_MINUTE`);
- аудит событий `auth.register` / `auth.login`;
- сетевой периметр НЛМК (портал не опубликован в интернет).

**Условие пересмотра:** до перевода в прод / подключения SSO (Blitz OAuth)
риск должен быть снят: регистрация закрывается либо переводится в
`pending` + подтверждение администратором/экологом.
